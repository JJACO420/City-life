# Changelog

All notable changes to City Life will be documented in this file.

## [Alpha 0.2] - 2025-12-10

### Added
- Version tracking system
- Version display in game UI (bottom right corner)
- Version information in page title and header
- Welcome message now includes version number
- CHANGELOG.md for tracking updates

### Changed
- Updated game title to include "Alpha 0.2" designation
- Enhanced branding with version identification

### Features
All features from Alpha 0.1 maintained:
- Complex life simulation with aging system
- Multiple life stats: Health, Energy, Hunger, Happiness
- Character attributes: Intelligence, Strength, Charisma, Creativity
- Career system with 5 job types and salary progression
- Education system with classes and exams
- Economy system with money management
- Procedurally generated 100x100 tile world
- 50 AI-controlled NPCs with unique personalities
- 8 different building types with interactive activities
- Day/night cycle with visual overlay
- Random life events system
- Social interaction mechanics
- Top-down pixelated graphics
- Comprehensive UI with stats tracking

## [Alpha 0.1] - 2025-12-09

### Initial Release
- First playable version of City Life
- Core life simulation mechanics
- Procedural world generation
- NPC system
- Building interaction system
- Basic UI and controls
